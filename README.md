A responsive and interactive **Single Page Application (SPA)** developed as part of my **Frontend Web Developer Internship at YuvaIntern**.

## 📌 Project Overview

The main objective of this project was to convert a given **wireframe into a fully responsive, accessible, and interactive website**.

The project was developed step-by-step during the internship:

* Wireframe to webpage conversion
* Responsive layout development
* Mobile navigation
* JavaScript interactivity
* Contact form validation
* Accessibility improvements
* Performance optimization
* Lighthouse testing
* Single Page Application simulation
* Client-side routing using the Browser History API

The project was limited to **HTML5, CSS3, and JavaScript**, without backend systems, databases, or external frameworks/libraries.

## 📅 Weekly Development

### Week 1 — Wireframe to Responsive Static Page

* Studied the provided wireframe.
* Created semantic HTML5 structure.
* Added CSS3 styling.
* Used Flexbox, CSS Grid, and media queries.

**Outcome:** Built the foundation of the responsive webpage.

### Week 2 — Responsive Web Design

* Implemented responsive navigation.
* Added and optimized images/elements.
* Improved layouts across different screen sizes.
* Tested the interface using browser developer tools.

**Outcome:** Improved cross-device responsiveness.

### Week 3 — JavaScript Interactivity

* Added a mobile navigation menu.
* Implemented contact form validation.
* Used JavaScript event listeners.
* Used `preventDefault()` for form handling.
* Practiced DOM manipulation.

**Outcome:** Added interactive and event-driven functionality.

### Week 4 — Accessibility & Performance

* Added skip-to-content functionality.
* Added visible focus states.
* Implemented ARIA labels.
* Added reduced-motion support.
* Tested the website using Lighthouse.

**Outcome:** Improved accessibility, performance, best practices, and SEO.

### Week 5 — Single Page Application Simulation

* Created dynamic Home, About, Services, and Contact sections.
* Implemented client-side navigation.
* Used `history.pushState()`.
* Used the `popstate` event.
* Implemented navigation without page reloads.

**Outcome:** Gained practical experience with SPA concepts and client-side routing.
